# 그라시안의 잠언 300

발타사르 그라시안 『신탁과 처세술』(1647) 300개 잠언의 해설·예시 웹앱 (PWA)

## 파일 구성
| 파일 | 역할 |
|---|---|
| `index.html` | 메인 앱 (잠언 300개 내장) |
| `widget.html` | 오늘의 잠언 위젯 (`?theme=light|dark|sepia&mode=random&size=small`) |
| `maxims.json` | 위젯·알림용 데이터 |
| `sw.js` | 서비스 워커 (오프라인, 매일 알림) |
| `manifest.webmanifest` | 앱 설치 정보·바로가기 |
| `og-image.png` | 링크 미리보기 이미지 (1200×630) |
| `icons/` | 앱 아이콘 |

## GitHub Pages 배포
1. 이 폴더의 파일을 모두 저장소 **루트**에 올립니다 (폴더 구조 유지).
2. Settings → Pages → Branch: `main` / `(root)` → Save.
3. 사이트 주소: https://todayplus.github.io/gracian300/ (링크 미리보기 이미지 절대 주소 반영 완료)

## 수정 후 반영
내용을 고친 뒤에는 `sw.js` 맨 위의 `VERSION = "v3"`를 `"v4"`처럼 올려 주세요. 설치된 앱이 새 버전을 받습니다.

## 매일 알림 지원 범위
- 안드로이드·PC 크롬에서 앱으로 설치: 앱을 닫아 둬도 백그라운드 알림 (시각은 기기 상태에 따라 조금 늦을 수 있음)
- 그 외 브라우저: 앱(탭)이 열려 있거나 다시 열 때 알림
- 아이폰: 홈 화면에 설치한 뒤 알림 권한 가능. 정확한 매일 알림은 **'캘린더 알림 추가'(.ics)** 권장
